# ARC Prize 2026 – Competitive Solver

## Overview
A reasoning-based system to solve ARC (Abstraction and Reasoning Corpus) tasks.

## Structure
- `data/` – ARC dataset (training, evaluation, test)
- `src/` – Core utilities and visualization
- `solver/` – Rule-based solver and search engine
- `experiments/` – Logs and experiment tracking
- `outputs/` – Predictions and Kaggle submissions

## Setup
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
